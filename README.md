## 📁 Descripción de Proyectos

### CipherScan
Plataforma SaaS de ciberseguridad multi-producto en desarrollo activo.  
- **Dashboard** interactivo de análisis de vulnerabilidades (paleta slate/copper)  
- **Landing page** curso de ethical hacking (estética cyberpunk, tipografía Orbitron/Rajdhani)  
- **Tienda** de plantillas pentest con carrito funcional y sistema de pagos  
- Stack: Python · FastAPI · JavaScript · HTML/CSS/SVG

### NLP Sentiment Pipeline
Pipeline end-to-end de análisis de sentimiento en español. Capstone MSc OBS Business School.  
- Cobertura dialectal: Peninsular, Mexicano, Argentino (voseo), Colombiano, Neutral LATAM  
- Evaluación con metodología **MQM** (Multidimensional Quality Metrics)  
- Modelos de clasificación multi-clase en producción  
- Stack: spaCy · NLTK · LangChain · Hugging Face · scikit-learn

### Smart City Analytics
Dashboard analítico de movilidad urbana para VECTALIA/Moviltik.  
- +20 KPIs de transporte público en tiempo real  
- ETL pipeline automatizado SQL + Python  
- Modelo predictivo de demanda y ocupación  
- Stack: Power BI · Python · SQL · Pandas · scikit-learn

### BI Dashboards HULKA
Suite de dashboards ejecutivos y automatización de reporting para consultoría retail.  
- Integración multi-sistema: ERP + CRM + Ventas + Stock  
- Forecasting mensual con regresión avanzada + DAX  
- Stack: Power BI · Tableau · DAX · SQL Server · Excel Avanzado

### ERP Automation
Automatización integral de procesos en Microsoft Dynamics NAV para EUROCASA.  
- Reducción del **60%** en tiempo de gestión de pedidos  
- Integración EDI con cadena de proveedores  
- Stack: Dynamics NAV · C/AL · SQL · Python · EDI

### Data Science desde Cero
Serie educativa integral en español: de cero a nivel Principal/Staff.  
- **7 volúmenes** · +500 páginas · ejercicios y proyectos prácticos  
- Vol. 1: Fundamentos · Vol. 2: Python Data · Vol. 3: ML Clásico · Vol. 4: NLP  
- Vol. 5: Deep Learning · Vol. 6: MLOps & GenAI · Vol. 7: Principal/Staff  
- Disponible gratuitamente como documentos Word/PDF

### AI Evaluation Framework
Framework estructurado para evaluación de calidad en sistemas LLM.  
- Rúbricas formales bilingüe ES/EN (Clinical Accuracy, Pedagogical Value, Safety)  
- Análisis comparativo multi-modelo: GPT-4, Claude, Gemini  
- Metodología MQM adaptada para IA generativa  
- Pipeline de evaluación automatizado con Python + LangChain

Este repositorio se despliega automáticamente en **GitHub Pages** mediante GitHub Actions.


### Estructura del repositorio

```
datanailytics.github.io/
├── index.html              # Portfolio principal (SPA)
├── README.md               # Este archivo
├── robots.txt              # SEO: configuración de rastreadores
├── sitemap.xml             # SEO: mapa del sitio
├── og-image.png            # Open Graph & Twitter Card image
└── .github/
    └── workflows/

```

```yaml

# Ver archivo completo en el repositorio
```
